# User Journey

## Product Philosophy

TripMind AI is an AI Travel Companion designed for university students.

Unlike traditional itinerary generators, TripMind AI accompanies users throughout the entire travel lifecycle — before, during, and after the journey.

---

# Current Journey (Without TripMind AI)

| Stage | User Action | Pain Point |
|--------|-------------|------------|
| Inspiration | 想出去旅行 | 不知道去哪、什么时候去 |
| Information Collection | 查小红书、知乎、B站、Google | 信息分散，攻略过时 |
| Planning | 自己整理路线、预算 | 非常耗时，容易遗漏 |
| Booking | 订酒店、机票 | 容易超预算，需要多个 App |
| During Travel | 查地图、翻译、攻略 | 来回切换多个应用 |
| After Travel | 保存照片、发朋友圈 | 旅行记录零散，难以回顾 |

---

# Future Journey (With TripMind AI)

| Stage | User Action | TripMind AI Value |
|--------|-------------|-------------------|
| Before Travel | 上传课表、输入预算、兴趣、目的地 | AI 推荐最佳出行日期，结合课程安排、节假日和预算生成旅行计划，并整理签证及最新入境政策 |
| Planning | AI 自动生成旅行方案 | 自动规划每天行程、交通、美食、景点及预算 |
| During Travel | 实时旅行 | AI 导游、景点讲解、AI 翻译、旅行问答、地图导航 |
| Travel Memory | 上传图片、视频、录音、文字 | 自动整理旅行内容，并记录地点、天气、时间等信息 |
| After Travel | 查看旅行档案 | 自动生成完整旅行档案，支持再次编辑、分享与回忆 |

---

# Core Value

TripMind AI is not just an itinerary generator.

It is an AI Travel Companion that supports users before, during, and after every journey.
