# TripMind-AI
An AI-powered travel companion built with Vue3, FastAPI and LLM.
TripMind AI 是一款面向大学生自由行场景的 AI 全流程旅行助手，
帮助用户完成从旅行规划、地图导航到旅行记录的完整体验。
